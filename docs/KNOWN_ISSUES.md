# Known Issues

## Open
- PDF export is currently supported through Print Preview / Print to PDF rather than a built-in PDF writer.
- Excel export is currently CSV-compatible export. Native XLSX export is planned for a later release.

## Resolved
- Operations dropdown focus issue resolved in v0.9D.
- Duplicate Operations buttons removed in v0.9C.

- Monitor v1.0.1 startup hardening during tester launch validation.

## Resolved in v1.1.5

- Operations transaction detail fields could be clipped.
- Camera capture required manually browsing to the captured picture after taking it.
- Default Windows application icon still appeared in the title bar/taskbar.
