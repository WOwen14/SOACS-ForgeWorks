# SOACS ForgeWorks Roadmap

**Current baseline:** v3.1.4 RC1  
**Current phase:** User testing and operational hardening

## Delivered

- Inventory and serialized-asset management
- Receive, issue, borrow, move, remove, and quantity-adjustment workflows
- Projects, reservations, material lists, and reusable kits/BOMs
- Borrowed-item and reorder-required tracking
- Procurement, vendor, manufacturer, lead-time, and cost fields
- Multi-document attachments and item photos
- Transaction history and Windows-user accountability
- Reporting, CSV export, Print Preview, and saved report templates
- Repository Manager with configurable profiles and health checks
- Local and shared repository configuration
- Backups, logs, reports, attachments, photos, temporary data, and feedback folders
- Live refresh across major workspaces
- Feedback packages with diagnostics and optional screenshots
- DPI/layout hardening for the primary 1920×1080 laptop test environment

## Active hardening

- Shared-database behavior with multiple operators
- Serialized-item validation and edge cases
- Project reservations, BOMs, and shortage calculations
- Repository switching and health recovery
- Report validation after inventory and project transactions
- User feedback from the v3.1.4 RC1 test cycle

## Planned

- Automatic offline detection and local repository fallback
- Synchronization queue and conflict-handling workflow
- Work orders
- Tool checkout
- Calibration tracking
- Barcode/QR label printing
- Native XLSX export
- Expanded automated and repeatable regression testing

Planned items are directional and are not represented as completed capabilities in the README or current release baseline.
