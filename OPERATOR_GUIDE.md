# SOACS ForgeWorks Operator Guide
Version: 3.1.4 RC1
Document Baseline: FW-OP-001

## Purpose
SOACS ForgeWorks supports Mission Fabrication Operations by combining inventory, projects, kits, documents, procurement, reporting, and repository management into one desktop application.

## Main Workspaces
- **Dashboard** - operational overview.
- **Operations** - receive, issue, borrow, move, return, scrap, cycle count, and adjust inventory.
- **Inventory** - manage item records, documents, photos, procurement, and history.
- **Projects** - track project inventory and transactions.
- **Kits** - define kit requirements and check readiness.
- **Reports** - generate inventory, project, borrowed, low inventory, transaction, and cost reports.
- **Administration** - manage categories, locations, custom fields, repository health, and feedback.
- **Settings** - configure workstation mode and repository profile.

## Submit Feedback
1. Click **Feedback** in the header.
2. Select the feedback type.
3. Enter comments.
4. Keep screenshot and diagnostics enabled.
5. Click **Submit**.

The feedback report is saved to the active repository.

## Documents and Attachments
Items support multiple documents. Documents are stored in the repository and can be opened or printed from the item record.

## Repository Profiles
The active repository profile is shown in the status bar. Profiles allow ForgeWorks to use Production, Test Lab, Standalone, or Offline repositories.

## Best Practice
Use the Feedback Center during testing so layout issues, workflow questions, crashes, and feature requests are captured with screenshots and system details.
